
# 🎙️ Radio Universal (PWA)

Sintonizador analógico-digital mundial de alta fidelidad. Escuchá miles de emisoras en tiempo real con una interfaz moderna, limpia y una mascota animada.

## ✨ Características Principales

* 📻 **Sintonización en 3 Bandas:** Soporte para FM (87.5-108 MHz), AM (530-1700 kHz) y Onda Corta / SW (3-30 MHz).
* 🌍 **Cobertura Global:** Conexión en vivo con la API pública de `Radio-Browser` con filtro automático de seguridad HTTPS.
* ⭐ **Gestión de Favoritos:** Guardá tus radios preferidas localmente (`localStorage` validado) con sintonización en un clic.
* 📱 **Progressive Web App (PWA):** Instalable como app nativa en Android, iOS, Windows, Linux y macOS sin tiendas de aplicaciones.
* ⚡ **Zero Dependencies / Portable:** Construido en JS puro (Vanilla), CSS moderno con Tailwind y ejecución en un solo archivo plano sin necesidad de entornos Node.js ni procesos de compilación.
* 🐢 **Baco Mode:** Mascota animada en pantalla que baila al ritmo de la reproducción en vivo.
